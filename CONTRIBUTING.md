# Contribuindo para Olho de Deus

Obrigado por querer contribuir! Siga estes passos simples:

1. Abra uma Issue descrevendo sua proposta (nova fonte, correção, dashboard).
2. Abra um Pull Request com um branch claro: `feature/<assunto>` ou `fix/<assunto>`.
3. Inclua referências e origem dos dados: URL, tipo de licença e data de obtenção.
4. Se adicionar scripts de ingestão, coloque testes básicos e exemplos de uso em `scripts/`.

Checklist para PRs que adicionam dados:
- [ ] Fonte pública e citada
- [ ] Licença compatível (ou permissão)
- [ ] Metadados (o que é, escopo temporal, granularidade)
- [ ] Pequeno script de verificação (opcional, mas recomendado)

Se precisar de ajuda com formatação ou scripts, marque uma Issue e eu posso gerar um PR inicial para você.
