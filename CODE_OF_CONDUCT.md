# Código de Conduta

Este projeto adota um Código de Conduta baseado nos princípios de respeito, inclusão e comunicação clara.

Resumidamente:
- Seja respeitoso com todos os contribuidores.
- Ataques pessoais, linguagem abusiva e assédio não serão tolerados.
- Contribuições devem focar no trabalho; críticas devem ser construtivas.

Se você testemunhar ou sofrer comportamento inapropriado, por favor abra uma issue privada (se disponível) ou entre em contato com o mantenedor: twowatcher.
